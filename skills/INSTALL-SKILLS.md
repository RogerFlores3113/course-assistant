# Install the Course Assistant skill

The skill teaches your AI app how to study with your saved course materials through the Course Assistant tools.

- Claude (Claude Code and the Claude app): copy `skills/claude/course-assistant/` into `~/.claude/skills/`.
- Codex: copy `skills/codex/course-assistant/` into `~/.agents/skills/`.

Connect the Course Assistant tools first (Connect AI page in the app), then ask for a primer, an exam guide,
practice questions, flashcards or "what did I miss". The skill never deletes anything and follows the graded-work
rule: it writes a twin problem instead of solving your own graded problem.
