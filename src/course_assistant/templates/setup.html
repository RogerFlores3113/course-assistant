Option 1: Claude Desktop or Codex (no API key)

Choose this if you already have the Claude Desktop app or Codex on this computer. Nothing to buy or copy: the button below adds Course Assistant to the app you pick.

{% if status.claude %}Claude Desktop is connected. {% endif %}{% if status.codex %}Codex is connected.{% endif %}

Afterwards, quit the app completely and open it again. Then start a chat and ask it about your course, for example "Use Course Assistant to make me a primer for my next lecture" or "Ask Course Assistant what Midterm 1 covers". The answers it writes are saved on the course's Guides tab here.

Option 2: An Anthropic API key

An API key is a long password that lets this app use Claude directly, from your own Anthropic account.

  1. Go to console.anthropic.com in your browser and sign in, or create an account.
  2. Open the API keys page and choose Create key. Give it any name, like Course Assistant.
  3. Copy the key. It starts with sk-ant-. Anthropic shows it only once, so copy it right away.
  4. Paste it below and press Save and test.

What it costs. Using the API is billed by Anthropic to your account, based on how much text is sent and received. This app only asks the AI when you ask a question or press a study button. Current rates are on the pricing page at console.anthropic.com, where you can also add a spending limit. The faster models cost less.

Option 3: A local model on this computer

Choose this to keep everything on your computer and pay nothing per question. You need a reasonably recent computer; smaller models write simpler answers.

  1. Install LM Studio (lmstudio.ai) and open it.
  2. Download a model from its Discover page, then load it.
  3. In LM Studio's Developer tab, start the local server. It shows an address, usually http://127.0.0.1:1234.
  4. Check the address and model name below, then press Save and test.
