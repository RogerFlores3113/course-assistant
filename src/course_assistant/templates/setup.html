Course Assistant finds the right passages in your own materials. It needs an AI to turn them into answers and study guides. Pick one of the ways below. They do not unlock the same things:

  • Claude Desktop or Codex: you ask in Claude Desktop or Codex. The Study and Ask buttons in this app stay off.

  • None of these yet: you can still add, read and search your materials. See "I don't have any of these" at the bottom.

Option 1: Claude Desktop or Codex (no API key)

Choose this if you already have the Claude Desktop app or Codex on this computer. Nothing to buy or copy: the next page adds Course Assistant to the app you pick. You ask in that app, and the Study and Ask buttons here stay off. Pick option 2 or 3 if you want the buttons in this app to work.

The button changes that app's own settings files, which are outside this app's folder. The next page lists the exact files before you press the button that writes them. Only apps that are installed are touched.

Option 2: An Anthropic API key

An API key is a long password that lets this app use Claude directly, from your own Anthropic account.

  1. Go to console.anthropic.com in your browser and sign in, or create an account.
  2. Open the API keys page and choose Create key. Give it any name, like Course Assistant.
  3. Copy the key. It starts with sk-ant-. Anthropic shows it only once, so copy it right away.
  4. Paste it below and press Save and test.

What it costs. Using the API is billed by Anthropic to your account, based on how much text is sent and received. This app only asks the AI when you ask a question or press a study button. Current rates are on the pricing page at console.anthropic.com, where you can also add a spending limit. The faster models cost less.

Option 3: A local model on this computer

Choose this to keep everything on your computer and pay nothing per question. You need a reasonably recent computer; smaller models write simpler answers.

  1. Install LM Studio (lmstudio.ai) and open it.
  2. Download a model from its Discover page, then load it.
  3. In LM Studio's Developer tab, start the local server. It shows an address, usually http://127.0.0.1:1234.
  4. Check the address and model name below, then press Save and test.

I don't have any of these

That is fine, and most people start here. A short, honest recommendation:

  • Cheapest choice that works well: an Anthropic API key (option 2) with one of the smaller, faster models in the Model list. You pay only for the questions you ask, and short study sessions use little.
  • Set a spending limit first. On console.anthropic.com, add a monthly spending limit before you paste the key, so a mistake cannot cost more than you chose.
  • No account at all: a local model (option 3) is free per question but needs a recent computer and gives simpler answers.
  • Not ready to decide: skip this step. You can add materials now and connect an AI later.
